# Defender for Cloud L400 customer value architecture lab

A 60-minute, read-only lab for Security Cloud Solution Architects. Prioritize cloud risks, investigate a critical attack path, and turn the evidence into a cloud-native application protection platform (CNAPP) architecture, a 30/60/90-day adoption roadmap, and a customer value narrative.

## Lab instructions

[Open the lab instructions and learner worksheet](./defender-for-cloud-l400-customer-value-architecture-lab.md).

The document includes:

- **Part 1:** Six timed activities, prerequisites, scenario, verification checkpoints, cleanup, and troubleshooting.
- **Part 2:** The learner worksheet for evidence, initiative comparison, recommendation prioritization, attack-path analysis, architecture, roadmap, and customer value narrative.
